# GitHub Pages Version (No Credit Card)

This is a static version of the intake form for public hosting via GitHub Pages.

Form submissions are sent by FormSubmit to `6077cro@walmart.com`.

## Important first-time setup
On first submission, FormSubmit sends a verification email to `6077cro@walmart.com`.
A manager must click that confirmation link once to activate submissions.

## Publish steps
1. GitHub repo Settings → Pages
2. Source: `Deploy from a branch`
3. Branch: `master`
4. Folder: `/docs`
5. Save

Your public URL will be:
`https://mistyhorton-sys.github.io/swing-door-driver-intake-/`

Use that URL in your QR code.
